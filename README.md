# 学习台 · Study Hub

数学分析与大学英语四六级的学习主导站。

- `/`：学习计划、今日任务、复习提醒、数学/英语分流
- `/english/`：大学英语四六级刷题（121 套）
- 德法题库：`https://lucy2025-creator.github.io/defa/`（已并入主导站入口，不改原站）
- 数学站/英语站接入德法同款验证码门禁：在线一次性核销 + 离线通行证；同一 origin 下凭证共享，德法已通过的浏览器可直接进入
