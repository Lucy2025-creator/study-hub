# 学习台 · Study Hub

数学分析与大学英语四六级的学习主导站。

- `/`：学习计划、今日任务、复习提醒、数学/英语分流
- `/english/`：大学英语四六级刷题（当前为 2025.06 四级第一套样卷）

## 当前状态

这是第一版骨架：主导站与英语站视觉、计划、样卷、选词/听力/阅读判分、错题本入口已打通。后续接入 2014–2026 真题批量数据、音频、逐题解析和 Supabase 云同步。

样卷文本与音频整理自公开的 CET 真题资源索引（CET46-Resources）。真题、音频、解析的著作权归原权利人；本仓库仅用于个人学习，不构成再传播授权。若公开部署，请自行确认授权范围。
