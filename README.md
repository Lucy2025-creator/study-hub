# 学习台 · Study Hub

数学分析与大学英语四六级的学习主导站。

- `/`：学习计划、今日任务、复习提醒、数学/英语分流
- `/english/`：大学英语四六级刷题（118 套）

## 当前状态

- **118 套题库**
  - 四级：2015.06 第一/二套 + 2020–2025 共 43 套
  - 六级：2015–2025 共 73 套
- 每套：听力 1–25（选项/答案，部分音频）、选词 26–35、匹配 36–45（多数含完整段落）、阅读 5+5、写作/翻译题面
- 已有：错题本、艾宾浩斯、错因标签、常错词、题库筛选/分页、PWA、Supabase 登录与云同步
- 2014–2019 四级完整套卷仍缺；2014–2023 音频只有 2024–2025 少量
- 2015 两套的匹配段落与音频仍不完整

## 真题来源

题库数据来自公开 CET 题库项目（`o-Sakurajimamai-o/cet-practice` 的 seed 数据库、`couldyyy9/cet-website` 的题库 JSON、`CET46-Resources` 的公开索引），部分老卷由 OCR/解析补全。真题、音频、解析的著作权归原权利人；本仓库仅用于个人学习，不构成再传播授权。若公开部署，请自行确认授权范围。
